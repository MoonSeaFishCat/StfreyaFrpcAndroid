# FRP配置向导使用指南

## 概述

FRP配置向导是一个简化的配置工具，帮助用户通过图形界面轻松创建FRP配置文件，无需手动编写复杂的配置文件。

## 功能特点

- 🎯 **分步引导**：通过4个简单步骤完成配置
- 📋 **配置模板**：提供常用服务类型的预设模板
- 🔧 **自动生成**：根据用户输入自动生成配置文件
- 📖 **详细帮助**：内置配置说明和示例
- 🌐 **多语言支持**：完全中文化界面

## 使用步骤

### 1. 启动配置向导

在主界面点击顶部的 ✨ 图标，或点击"添加配置"按钮选择"快速设置"。

### 2. 选择配置模板

选择您要穿透的服务类型：

- **网站服务 (HTTP)**：用于网站服务穿透
- **SSH远程连接**：用于远程终端连接
- **远程桌面 (RDP)**：用于Windows远程桌面
- **自定义服务**：其他TCP/UDP服务

### 3. 配置服务器信息

填写您的FRP服务器信息：

- **服务器地址**：您的服务器IP地址或域名
- **服务器端口**：通常使用7000
- **认证令牌**：用于安全验证，请与服务器端保持一致

### 4. 配置服务信息

设置要穿透的内网服务：

- **服务名称**：为您的服务起个名字
- **本地端口**：内网设备上运行的服务端口
- **远程端口**：通过公网访问时使用的端口

### 5. 预览和保存

查看生成的配置文件，确认无误后保存。

## 配置示例

### 网站服务穿透

```toml
[common]
server_addr = your-server.com
server_port = 7000
token = your-token

[web]
type = http
local_ip = 127.0.0.1
local_port = 8080
custom_domains = your-domain.com
```

### SSH远程连接

```toml
[common]
server_addr = your-server.com
server_port = 7000
token = your-token

[ssh]
type = tcp
local_ip = 127.0.0.1
local_port = 22
remote_port = 6000
```

### 远程桌面 (RDP)

```toml
[common]
server_addr = your-server.com
server_port = 7000
token = your-token

[rdp]
type = tcp
local_ip = 127.0.0.1
local_port = 3389
remote_port = 7001
```

## 常见问题

### Q: 如何获取服务器信息？
A: 您需要一台具有公网IP的服务器来运行FRP服务端。服务器信息由您的服务器管理员提供。

### Q: 端口冲突怎么办？
A: 确保远程端口在服务器上没有被其他服务占用，可以尝试使用其他端口号。

### Q: 配置后无法连接？
A: 请检查：
1. 服务器地址和端口是否正确
2. 认证令牌是否与服务器端一致
3. 服务器防火墙是否开放相应端口
4. 本地服务是否正在运行

### Q: 如何修改已创建的配置？
A: 点击配置卡片上的编辑按钮，可以修改配置文件内容。

## 高级配置

对于需要更复杂配置的用户，可以：

1. 使用配置向导创建基础配置
2. 点击编辑按钮进入高级编辑模式
3. 手动修改配置文件内容

## 安全建议

- 使用强密码和安全的认证令牌
- 定期更新FRP版本
- 不要将敏感服务暴露到公网
- 建议使用HTTPS保护网站服务
- 限制远程端口的访问权限
